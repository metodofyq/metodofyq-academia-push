## 🏆 OPCIÓN RECOMENDADA (La Mejor)

### **Método: Documentos Separados + 1 Prompt Coordinador**

```
Estructura ideal:

tema-19-entrega/
  ├── TEMA-19-N0-INDICE.md
  ├── TEMA-19-N1-PALABRAS-CLAVE.md
  ├── TEMA-19-N2-DESARROLLO.md
  ├── TEMA-19-N3-REDACCION.md
  ├── TEMA-19-N4-LEGISLACION.md
  ├── TEMA-19-PROPUESTA.md
  └── INSTRUCCIONES.txt (el prompt)
```

### ¿Por qué es mejor?

```
✅ VENTAJAS:
  - Cada nivel es independiente (fácil de revisar)
  - Si un nivel está mal, solo reemplazas ese archivo
  - Claude puede procesar cada nivel separadamente
  - Más fácil de mantener en versión control
  - Menos riesgo de cortar texto por límite de caracteres
  - Puedes preparar archivos con anticipación

❌ DESVENTAJAS (vs monolítico):
  - Más archivos que gestionar
  - Tienes que pegar cada uno en Claude
```

## 📊 COMPARATIVA: FORMATOS

| Formato | Ventajas | Desventajas | Cuándo usar |
|---------|----------|------------|-----------|
| **Archivos .md separados** | ✅ Modular, fácil revisar, cada uno independiente | ⚠️ Más archivos | ⭐ RECOMENDADO |
| **Todo en 1 .md** | ✅ Un archivo, simple | ❌ Difícil de revisar, riesgo truncamiento | Si es muy pequeño |
| **Prompt + pegar inline** | ✅ Sin archivos | ❌ Propenso a errores, poco profesional | No recomendado |
| **.txt plano** | ✅ Simple | ❌ Sin formato, difícil de leer | Solo como fallback |

## 🚨 ERRORES COMUNES A EVITAR

### ❌ Error 1: Entregar TODO en un único prompt gigante
```
MALO:
[Pega N0 + N1 + N2 + N3 + N4 + Propuesta + 5,000 líneas]

MEJOR:
Archivo separado por nivel (+ limpio, menos errores)
```

### ❌ Error 2: N1 con definiciones
```
MALO:
Conocimiento racional: La forma de saber que es sistemática y verificable
Objetividad: La capacidad de reducir sesgos mediante procedimientos compartidos

MEJOR:
- Conocimiento racional
- Objetividad
- Sistemático
(Solo términos, sin explicar)
```

### ❌ Error 3: Archivos .txt en lugar de .md
```
MALO: TEMA-19-N0.txt (sin formato)

MEJOR: TEMA-19-N0-INDICE.md (con encabezados Markdown)
```

### ❌ Error 4: N3 incluyendo legislación
```
MALO:
## CONCLUSIONES
El marco legislativo en Madrid establece...

MEJOR:
## CONCLUSIONES
La ciencia es un proceso dinámico...
(Legislación va SOLO en N4)
```

```
MALO:

Andalucía
```
